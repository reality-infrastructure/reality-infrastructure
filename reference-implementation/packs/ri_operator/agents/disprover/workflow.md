# disprover — the workflow of the past

Before this agent, the person who built a thing also decided whether it was
safe to ship. Sometimes a second person was asked, was shown the builder's own
summary, and agreed with it. Nobody wrote down the assumptions first, so nobody
could later say which one had been wrong. Eight questions per action, asked
from memory when they were asked at all; no record of the answers.
