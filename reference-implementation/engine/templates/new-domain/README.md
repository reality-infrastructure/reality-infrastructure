# __PACK__ — domain pack

Generated by `python -m engine.scaffold new-domain __PACK__`. The engine
supplies mechanism; this pack supplies nouns. Nothing in `engine/` knows this
pack exists.

## Order of adoption

1. Harness one existing manual workflow as `agents/worker` (prove the pattern
   on the past). Fill `workflow.md` first: who did it, how long, what they
   checked. Locate the real historical data for `eval/golden.jsonl` and count
   it before writing code; fewer than 10 real cases is a STOP.
2. Promote the human-facing summary job to `agents/orchestrator`.
3. Write `problem.md`; build the specialist + verifier only once real outcomes
   exist for a golden set.
4. License everything general behind adapters; fill `VENDOR-SCORECARD.md`
   before building any adapter in-house.
5. Turn the crank weekly (`python -m engine.crank __PACK__ --week YYYY-Www`)
   and climb `IMPROVEMENT-ORDER.md` in order.
