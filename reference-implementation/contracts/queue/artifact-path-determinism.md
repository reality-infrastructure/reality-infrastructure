## Context (read first, do not skip)

The suite's pass/fail depends on the CASING of the directory pytest is
invoked from. At the same HEAD, clean tree:
`C:\Users\newce\Reality-Infrastructure\reference-implementation` → 675
passed; the lowercase casing of the identical directory → 674 passed, 1
failed (`test_audit_remediation.py::test_shipped_artifacts_match_live_machine`).

Cause (traced, not guessed): the shipped
`audit/out/attested-remediated-2026-08-02/delta_table.json` embeds absolute
machine paths in `meta.inputs` ("C:/Users/newce/Reality-Infrastructure/...",
generated by rerun_remediated's meta construction), and the test rebuilds
those strings from `Path(__file__)` (tests/test_audit_remediation.py:30-37),
whose casing follows the invocation path.

Why this is a defect and not a curiosity: a stranger cloning from the org
(lowercase `reality-infrastructure`) gets a red test on shipped-artifacts-
match-live-machine — a determinism failure, in the repo whose entire pitch
(METHODOLOGY.md) is determinism. "675 passed" is currently a claim about
shell history.

**Goal of this contract:** the full suite passes from any casing of the repo
path and from a fresh stranger-clone, with artifact meta paths portable
(repo-relative), under the audit's existing amendment discipline.

## Non-Goals (hard boundaries)

- Do NOT modify the engine (`ri_core/`) or the frozen domain-layer modules.
- Do NOT change any verdict: the 5-verdict tables, delta transitions, and
  contested set are untouched — this contract changes WHERE paths are
  written, never what was concluded.
- Do NOT touch the frozen baselines `audit/out/attested-2026-08-02/` beyond
  what the meta-path change strictly requires; prior-run directories that
  need no change get none.
- Do NOT fix silently: every changed byte arrives as a dated §9 amendment in
  audit/PREREGISTRATION.md with re-pinned hashes in the same commit
  (the A2 precedent, PREREGISTRATION.md:182-186).

## Deliverables

- rerun_remediated (and any sibling runner writing meta.inputs) emits
  repo-relative POSIX paths — never absolute, never machine- or
  casing-dependent.
- Regenerated shipped artifacts under audit/out/attested-remediated-2026-08-02/
  whose bytes differ ONLY in meta.inputs path strings (byte-diff pasted as
  gate evidence).
- tests/test_audit_remediation.py meta construction made path-portable to
  match.
- PREREGISTRATION.md §9 amendment recording BEFORE/AFTER and re-pinning.
- A regression test that fails if any shipped artifact ever again embeds an
  absolute path (grep-class assertion over audit/out/*.json).

## Method (ordered, do not reorder)

1. Baseline both casings at HEAD; paste both outputs (the defect reproduced
   before any edit).
2. Write the §9 amendment (BEFORE/AFTER path forms) — commit it before code.
3. Change meta construction; regenerate; byte-diff old vs new artifacts.
4. Re-pin; add the no-absolute-paths regression test.

## Gates (deterministic, all must pass)

- **Gate 1 — Both casings:** `pytest -q` green (675+) from the capitalized
  AND lowercase invocation paths, outputs pasted.
- **Gate 2 — Stranger clone:** fresh `git clone` into a lowercase path on
  this machine; suite green; output pasted.
- **Gate 3 — Nothing else moved:** byte-diff of regenerated artifacts shows
  changes confined to meta.inputs path strings; verdict arrays byte-identical.
- **Gate 4 — Regression armed:** the no-absolute-paths test fails when fed a
  deliberately absolute path (watch it fail before trusting it).

## Acceptance

- All gates pass with evidence pasted into the contract's SCOREBOARD.
- Amendment committed strictly before the code change (git-verifiable).
- Suite count reported verbatim; no reduction from 675.

## Kill Criteria

- If regeneration changes ANY verdict, transition label, or contested-set
  member — STOP. That is a different and bigger finding than path casing;
  report it, do not fold it into this contract.
- If the meta-path change cannot be made without editing `rules.py` or
  `engine.py` classification surfaces — STOP and report the coupling.
